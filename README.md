# NAMA AI Trader — MVP
نسخة أولية لماسح فرص الأسهم الأمريكية.

## التشغيل
1. ثبّت Python 3.11+
2. `python -m venv .venv`
3. فعّل البيئة الافتراضية
4. `pip install -r requirements.txt`
5. انسخ `.env.example` إلى `.env` وضع مفتاح Alpha Vantage.
6. `streamlit run app.py`

## ملاحظة
هذه النسخة تعليمية/اختبارية. الإشارة احتمالية وليست توصية أو ضمانًا للربح.
